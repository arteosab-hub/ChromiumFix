# ChromiumFix

**Фикс вылетов Google Play Market на Xiaomi.eu HyperOS 2**

Модуль для Magisk / KernelSU, который решает проблему крашей Google Play с ошибкой `udp_socket_posix.cc` на кастомных прошивках Xiaomi.eu.

---

## 📋 Проблема

На прошивке **Xiaomi.eu HyperOS 2** Google Play Market периодически вылетает с ошибкой:

```
signal 5 (SIGTRAP), code 1 (TRAP_BRKPT)
Abort message: '[FATAL:udp_socket_posix.cc(315)] Check failed: . : Bad file descriptor (9)'
```

**Причина:** сломанная библиотека `libchromium_net.so` внутри `com.android.tethering.apex`, которая используется сетевым стеком Cronet (Chromium Networking).

---

## ✅ Решение

Модуль заменяет сломанную библиотеку `libchromium_net.so` на рабочую версию из глобальной (Global) прошивки Xiaomi, а также отключает QUIC (UDP-протокол), который вызывает краши на Xiaomi.eu.

---

## 📦 Версии

| Версия | QUIC | Автообновление Google Play | Статус |
|--------|------|---------------------------|--------|
| **v2.1 stable** | ❌ Выключен | ✅ Заблокировано | ⭐ **Рекомендуется** |
| v2.2 beta 2 | ✅ Включён | ✅ Заблокировано | ⚠️ Тестовая |

- **v2.1 stable** — стабильная версия, QUIC отключён, автообновление Play Market заблокировано.
- **v2.2 beta 2** — экспериментальная версия с включённым QUIC. Если Google Play начнёт падать — вернитесь на v2.1.

## 🚀 Установка

1. Скачайте нужную версию модуля (`.zip`) из [Releases](../../releases).
2. Откройте **Magisk** или **KernelSU** → **Модули** → **Установить из хранилища**.
3. Выберите скачанный `.zip` файл.
4. Перезагрузите устройство.

### Проверка работы

После перезагрузки проверьте лог:

```bash
su -c "cat /data/local/tmp/ChromiumFix.log"
```

Ожидаемый вывод:
```
[...] ChromiumFix v2.1 started
[...] SUCCESS: Mounted to /system/apex/com.android.tethering@340090000/lib64/libchromium_net.so
[...] Auto-update blocked
[...] Done
```

## 🗑️ Удаление

1. Откройте Magisk / KernelSU → **Модули**.
2. Нажмите на модуль **ChromiumFix** → **Удалить**.
3. Перезагрузите устройство.

Или просто отключите модуль (toggle) и перезагрузитесь — система вернётся к исходному состоянию.

---

## 🐛 Известные проблемы

- **v2.2 beta 2** — при включённом QUIC Google Play может продолжать падать на некоторых сборках Xiaomi.eu. Используйте v2.1 stable.
- Если модуль не появляется в Magisk после установки — убедитесь, что ZIP не повреждён, и попробуйте установить заново.
